## What the run does
1. `jc_ncbi_fetch` (x2, pri and alt): the shared fetcher reads the NCBI folder for
   GCA_062019780.1 and GCA_062019781.1 (`genomes/all/GCA/062/019/78{0,1}/`), downloads
   `*_genomic.fna.gz`, `*_assembly_report.txt` and `md5checksums.txt` to jc scratch, and checks
   both md5s against NCBI's; a mismatch is retried, then fails the job.
2. `jc_gfastats` (x2): three gfastats passes over each FASTA:
   `--tabular` (summary totals), `--path-report --tabular` (one row per FASTA record) and
   `--out-coord g` (gap coordinates: runs of N or n, 0-based half-open BED).
3. `jc_assembly_stats_publish` (x1): cross-checks each assembly's three outputs (scaffold count
   and total length, gap count and total gap bp, per-record gap bp = path - segment length, every
   gap inside its record; any disagreement fails the job), then writes the Tier 2 run folder.
   `_MANIFEST.txt` is the t2t bucket's header-only block, as in M02: `describes:` (the SPEC row),
   `source:`, `dest:`, `job:`, `scope: metric`, `finished:`, `objects:`, `size:`, then `lane: jc`,
   `commit:`, `run_id:` and `spec_id:`. `run_info.json` records `commit:` (ticket_commit), both
   image digests, the gfastats command lines and per-assembly record and gap counts.

## Expected outputs
`s3://t2t/ROS_Cfam_2.0/jc/<run_id>/`:
- `gfastats.tsv`: long format, `assembly haplotype accession scope seq_id metric value`.
  `scope=assembly` rows are gfastats' summary (32 metrics per assembly, seq_id NA);
  `scope=sequence` rows are its per-record report (10 metrics per record: Comment, path and
  segment length, Contig N, A/C/G/T, soft-masked bases, Is circular). If the FASTAs hold the 41
  pri and 38 alt records the 2026-11-22 assembly reports list (tickets/sf/M02.md), that is
  32 + 410 + 32 + 380 = 854 rows.
- `gaps.bed`: BED4, `seq_id start end assembly`, every gap in both haplotypes.
- `inputs.tsv`: URL, NCBI md5, observed md5 and size for each downloaded file (the md5 check).
- `run_info.json`, `sha256sums.txt`, `_MANIFEST.txt`

Scratch: `/scratch.global/friedlab_T2TEVAL/jc/jc/ncbi/<assembly>/` (about 1.5 GB of downloads)
and `.../jc/jc/<run_id>/` (small text files).

Numbers are diagnostic-only. Chromosome counts against NCBI (40 pri, 38 alt), which records are
chromosomes, and any per-chromosome gap statement are for jc/M01-report, not this run.
